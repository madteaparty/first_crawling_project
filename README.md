# 메가박스 영화 및 상영시간표 크롤링 학습 기록

Python의 Selenium으로 동적 페이지를 조작하고 BeautifulSoup으로 HTML을 해석한 학습 프로젝트입니다. 영화 목록을 살펴본 뒤 관심 영화의 서울 극장별 상영시간과 좌석 정보를 모으는 두 단계를 구현했습니다.

**이 저장소는 당시 작업 기록입니다.** 원본 Notebook, 실행 출력, CSV는 보존합니다. `movie.ipynb`의 `2025.11.29`, `주토피아`, `서울`은 당시 실습 조건이며 현재 날짜로 자동 변경하지 않습니다. 최신 예매 정보 제공 서비스가 아닙니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `crawling_code/megabox_Crawling.ipynb` | 전체영화 목록 수집 |
| `crawling_code/movie.ipynb` | 주토피아 2 서울 상영정보 수집 |
| `megaboxCrawling.csv` | 보관된 영화 목록 164행 |
| `Megabox_Zootopia2_Seoul_1129.csv` | 보관된 상영정보 451행, 극장명 18개 |
| `requirements.txt` | 원본 import와 Notebook 실행용 의존성 후보 범위 |
| `scripts/validate_data.py` | 네트워크 없이 두 CSV의 형식과 내부 일관성 검사 |
| `tests/test_validate_data.py` | 검증 코드의 정상/오류 입력 테스트 |
| `LICENSE` | 저장소 코드의 라이선스 확인 위치 |

행 수는 헤더를 제외한 저장 파일 기준입니다. 상영일은 코드의 지정값에서 확인한 것으로, CSV 자체에는 영화명과 상영일 열이 없습니다. 정확한 수집 시각이나 전체 극장 수집의 완전성은 파일만으로 증명할 수 없습니다.

## 작동 원리: 실제 코드 분석

### 1. 영화 목록 (`megabox_Crawling.ipynb`)

1. `webdriver.Chrome()`으로 `https://www.megabox.co.kr/movie`에 접속합니다.
2. 더보기 버튼을 반복 클릭하고 영화 목록 영역의 `outerHTML`을 가져옵니다.
3. BeautifulSoup으로 `ol > li`를 순회하며 제목, 요약, 평점, 예매율 등을 추출합니다.
4. pandas DataFrame을 UTF-8 BOM CSV(`utf-8-sig`, `index=False`)로 저장합니다.

더보기와 목록 영역에 절대 XPath가 사용됩니다. 대기 조건은 새 항목 수 증가가 아니라 기존 항목의 존재이므로 추가 로딩 완료를 보장하지 않습니다. 여러 필드의 예외를 빈 문자열로 처리하며, 화면 유형 플래그도 실제 제공 여부와 일치한다고 보장할 수 없습니다. 사용하지 않는 `initial_movie_box` 변수도 남아 있습니다.

### 2. 상영정보 (`movie.ipynb`)

1. `https://www.megabox.co.kr/booking`에 접속하고 `iframe#frameBokdMBooking`으로 전환합니다.
2. `button[movie-nm]` 중 이름에 `주토피아`가 포함된 첫 버튼을 클릭합니다.
3. `button[date-data]`에서 `2025.11.29`가 포함된 날짜를 찾고 서울 지역을 선택합니다.
4. 극장 영역을 다섯 번 스크롤한 뒤, 클래스에 `disabled`가 없는 극장명을 수집하고 앞의 18개만 사용합니다.
5. 극장별로 클릭한 뒤 `button[play-start-time]` 안의 시간, 상영관, 타입, 좌석을 파싱합니다. 다음 극장 처리 전에는 선택 해제를 시도합니다.
6. 결과가 있으면 CSV로 저장하고 `finally`에서 브라우저를 종료합니다.

두 Notebook 사이에 자동 연결은 없습니다. 첫 단계의 CSV가 두 번째 단계의 영화 선택에 입력되지는 않습니다. 영화나 날짜 버튼을 못 찾아도 명시적으로 실패하지 않으며, 극장 클릭 누락이나 선택 해제 실패로 이전 화면 또는 여러 극장의 결과가 섞일 가능성이 있습니다. 18개 제한은 당시 코드의 값이며 서울 전체 극장 수를 뜻하지 않습니다.

## 데이터 구조

### 영화 목록 CSV

| 열 | 저장 형태 / 의미 |
| --- | --- |
| `rank` | 순위 표시 문자열, 예: `1위` |
| `img_src`, `img_title` | 포스터 URL과 alt 텍스트 |
| `mx4d`, `dolby`, `atmos` | 해당 태그와 텍스트 존재 여부를 0/1로 기록 |
| `mega_only` | `div.megaOnly` 존재 여부를 0/1로 기록 |
| `summary` | 영화 소개, 줄바꿈 포함 가능 |
| `score` | 평점 표시 문자열, 예: `9.4점` |
| `title` | 영화 제목 |
| `booking_rate` | 표시 문자열, 예: `예매율 54.4%` |
| `release_date` | 표시 문자열, 예: `개봉일 2025.11.26` |
| `like` | 좋아요 표시 문자열, 예: `1.7k` |

평점, 예매율, 좋아요는 정규화된 숫자가 아닙니다. 빈 필드는 정보 부재와 파싱 실패를 구별하지 못합니다.

### 상영정보 CSV

| 열 | 저장 형태 / 의미 |
| --- | --- |
| 이름 없는 첫 열 | `index=True`로 저장된 pandas 행 인덱스, 상영 식별자 아님 |
| `도시` | 코드가 기록하는 고정값 `서울` |
| `극장` | 선택 대상으로 사용한 극장명 |
| `시작시간` | `09:00` 같은 영업일 기준 시간 문자열 |
| `종료시간` | 원본은 `~10:58`처럼 `~` 포함 |
| `상영타입` | 예: `2D(자막)`, `2D(더빙)` |
| `상영관` | 상영관 표시 문자열 |
| `잔여좌석`, `전체좌석` | CSV에서는 텍스트로 읽고 검증할 때 정수 여부 검사 |

자정 이후를 `~26:38`처럼 24시 이상으로 표시한 행도 있으므로 일반적인 00~23시만 허용하는 파서로 읽으면 안 됩니다. 잔여좌석은 당시 화면 값이며 현재 값이 아닙니다.

## 설치와 실행

### 보관 데이터만 검토하기 (브라우저 불필요)

Python 3.10 이상을 권장합니다. 검증 스크립트는 표준 라이브러리만 사용하므로 pip 설치가 필요 없습니다. 저장소 루트에서:

```bash
git clone https://github.com/madteaparty/first_crawling_project.git
cd first_crawling_project
python scripts/validate_data.py
python -m unittest discover -s tests -v
```

다른 파일은 `python scripts/validate_data.py --schedule path/to/schedule.csv --movies path/to/movies.csv`로 지정합니다. 오류가 있으면 종료 코드 1, 경고만 있으면 0입니다. 원본은 수정하지 않습니다.

검사 범위는 열 이름과 순서, 빈 데이터, 행별 열 개수, 상영정보 필수값, 00~29시 시간 형식, `0 ≤ 잔여좌석 ≤ 전체좌석` 및 양수 전체좌석, 영화 제목과 0/1 플래그입니다. 완전히 같은 행은 경고합니다. 이름 없는 인덱스는 중복 비교에서 제외합니다. **통과해도 실제 영화/날짜 선택 성공, 사이트 정보와의 일치, 누락 없음은 증명되지 않습니다.**

### 원본 Notebook 환경 준비 (현재 사이트 실행 미검증)

Chrome이 필요합니다. 가상환경 활성화는 사용하는 OS에 맞게 수행합니다.

```bash
python -m venv .venv
# macOS/Linux
source .venv/bin/activate
# Windows PowerShell에서는 위 명령 대신:
# .venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m ipykernel install --user --name megabox-study --display-name "Megabox study"
python -m jupyterlab
```

Jupyter에서 `Megabox study` 커널을 선택합니다. 원본 메타데이터는 각각 Python 3.13.5와 3.14.0을 기록하지만 당시 패키지 버전은 남아 있지 않습니다. requirements는 당시 환경 복원용 lock 파일이 아니며, 이 범위 전체의 설치와 호환성을 확인하지 않았습니다. 검증된 새 환경이 생기면 Python/Chrome/드라이버 버전과 함께 별도 lock 파일을 남기는 것이 좋습니다.

`webdriver.Chrome()` 초기화에는 호환 드라이버가 필요합니다. Selenium의 드라이버 자동 관리가 가능한 환경에서도 최초 다운로드와 네트워크 권한이 필요할 수 있습니다. 실패하면 브라우저/드라이버 호환성과 설치 경로를 확인하세요.

**실행 전 원본을 복사하여 별도 작업 폴더에서 실험하세요.** 두 Notebook은 실행 작업 디렉터리에 같은 이름의 CSV를 저장하므로 기존 파일을 덮어쓸 수 있습니다. 첫 Notebook에는 `! pip install` 셀도 있어 환경이 변경될 수 있습니다. 두 번째는 과거 날짜가 현재 화면에 없어 의도한 조건으로 재실행할 수 없습니다. 원본 그대로의 재실행은 당시 데이터 재현을 보장하지 않습니다.

## 확인한 것과 확인하지 않은 것

2026-10-17 정비 시 실제 Notebook 소스와 저장 CSV를 분석했습니다. 오프라인 검증 결과는 상영정보 451행 오류 0/인덱스 경고 1, 영화 목록 164행 오류 0/경고 0이며 검증 코드 테스트 4개가 통과했습니다.

새 가상환경에서의 의존성 설치, Chrome 실행, 현재 메가박스 UI 자동 조작, 수집 결과와 실제 사이트의 대조는 수행하지 않았습니다. Notebook에 남아 있는 출력은 과거 기록이며 이번에 실행한 결과가 아닙니다.

## 향후 개선 제안 (미구현, 원본 보존)

- 별도 모듈 또는 새 Notebook에서 `movie_name`, `show_date`, `region`, `output_path`를 입력받습니다. 날짜는 명시적인 `YYYY-MM-DD` 입력을 우선하고, 오늘 기본값이 필요하면 Asia/Seoul 기준을 사용합니다. 날짜를 바꾸는 것만으로 해당 상영일이 예약 가능해지는 것은 아닙니다.
- 표시 가능한 영화/날짜 목록을 먼저 확인하고 정확히 하나를 선택합니다. 영화명 부분 일치가 여러 건이거나 날짜가 없으면 저장 전에 중단합니다. 선택 후 화면 상태도 다시 검증합니다.
- 절대 XPath를 속성 기반 선택자로 교체하고 선택자를 한곳에 모읍니다. 현재 속성 역시 사이트 변경에 영향을 받으므로 영구 안정성을 보장하지 않습니다.
- 고정 `sleep`을 iframe 진입 가능, 클릭 가능, 선택 상태, 상영목록 변경 등의 명시적 대기로 대체합니다. 재시도와 최대 반복 횟수를 제한합니다.
- 극장 18개 제한을 설정으로 분리하고 목록 로딩 완료를 확인합니다. 극장 선택/해제를 검증하고 실패한 극장과 원인을 남겨 이전 화면 오수집을 방지합니다.
- 광범위한 `except:`를 구체적 예외와 오류 로그로 바꾸고 첫 Notebook에도 `try/finally`로 브라우저 종료를 보장합니다.
- 신규 데이터에는 영화명/영화 ID, 상영일, 수집 시각과 시간대, 극장/상영 ID, 출처 URL을 추가하고 `index=False`로 저장합니다. 기존 CSV는 변환하지 않습니다.
- HTML 파싱과 브라우저 조작을 분리하고 허용된 HTML fixture로 파서를 테스트합니다. 온라인 크롤링을 자동 CI나 정기 실행에 바로 연결하지 않습니다.

## 사이트 이용 정책과 데이터 사용

메가박스의 [이용약관](https://www.megabox.co.kr/support/terms)과 [robots.txt](https://www.megabox.co.kr/robots.txt)를 실행 전에 직접 확인하세요. 2026-10-17에는 약관 페이지 접근을 확인했으나 robots.txt 내용은 확인하지 못했습니다. 이 문서는 자동 수집이 허용되었다고 판단하거나 허가를 대신하지 않습니다. robots.txt만으로 데이터 재배포 권한을 판단해서도 안 됩니다.

허용 범위가 불명확하면 운영사에 문의하고 허용된 범위에서만 실행합니다. 요청량을 최소화하고 불필요한 재실행과 병렬 수집을 피하며 차단/접근 제한 발생 시 중단합니다. CAPTCHA나 로그인 제한을 우회하지 않습니다. 예매와 결제 또는 좌석 점유를 자동화하지 않습니다.

포스터, 줄거리 등 제3자 콘텐츠의 권리는 저장소 코드 라이선스와 별개입니다. 기존 CSV는 실습 기록이며 재배포나 상업적 이용의 허가를 의미하지 않습니다. 외부 활용 전 출처와 권리 조건을 확인해야 합니다.
